What actually changes
✓ Splitting changes:
  • Peak drops 17% on 2×/wk (9.0 → 7.5)
  • Peak drops 22% on 3×/wk (9.0 → 7.1)
  • Trough rises 25–35% (4.0 → 5.0/5.4)
  • Curve is smoother — fewer wild swings
✗ Splitting does NOT change:
  • Average drug level (6.25 vs 6.5 mg-eq — basically identical)
  • AUC / total exposure — identical
  • Weight loss efficacy — driven by AUC, not peaks
  • Time to steady state — ~28 days regardless
  • Total cost / mg used — same
The practical take for you
Your 50-unit weekly = 2.24× swing between peak and trough.
If you're getting:
  • 🤢
    Day 1–2 nausea spikes → splitting will help (lower Cmax)
  • 😴
    Day 6–7 hunger creep back → splitting will help (higher trough)
  • 😎
    Tolerating fine and losing weight → no reason to split. Same result.
⚖ Bottom Line
Splitting Reta is a side-effect strategy.
Not a magic-bullet strategy.
